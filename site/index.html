IntelliJ IDEA · SCTP · macOS

SCTP development on a Mac, for real.

macOS has no SCTP. This script runs IntelliJ IDEA in a Linux container with lksctp-tools and a JDK, and shows its window on your macOS desktop through XQuartz.

Terminal
$ git clone https://github.com/sftwnd/idea-docker-X11.git
$ cd idea-docker-X11
$ ./idea.sh    # downloads IDEA, builds the image, starts the IDE

The problem

Linux for the protocol, macOS for everything else

To develop a Java application that talks SCTP you need Linux with lksctp-tools. The Mac you work on has no native SCTP support.

A full Linux desktop in a virtual machine is heavy. Here only IntelliJ IDEA lives in the container, and the X11 window is drawn by XQuartz on the macOS desktop. You edit, build and debug against a real SCTP stack, and your projects, Maven and Gradle stay on the host.

What the script does

One command, from nothing to a running IDE

Run ./idea.sh. It only does the work that is still missing, and --dry-run shows the plan without changing anything.

  1. Downloads what is not there yet

    The latest IntelliJ IDEA when there is no local installation, the latest Maven 3 and Gradle, and the JDK API documentation.

  2. Verifies the downloads

    The published checksums are checked before anything is unpacked.

  3. Builds the image

    From the committed Dockerfile, only when the image is missing or its inputs have changed.

  4. Creates the container

    With the IDE, Maven, Gradle and your projects mounted from the host, and a home volume that keeps the IDE settings.

  5. Starts IntelliJ IDEA

    On the XQuartz display. docker stop shuts the IDE down gracefully.

Features

Built for SCTP work, not just for a Linux shell

The container is configured through the options of docker create, so each behaviour below is a setting rather than a manual step.

SCTP

Working SCTP stack

lksctp-tools, iproute and procps-ng in the image. Check it with docker exec idea-IU checksctp.

RFC 4895

SCTP authentication

net.sctp.auth_enable is on by default, so authenticated chunks work out of the box.

RFC 6951

SCTP over UDP

Set IDEA_SCTP_UDP_PORT and IDEA_SCTP_ENCAP_PORT to test the UDP encapsulation.

multihoming

Network namespaces

In a privileged container ip netns add peer gives you a second host to test multihoming against.

JDK

JDK 25 by default

Choose 21 or 25 with IDEA_JDK_VERSION. The matching API documentation is downloaded for you.

host

Your tools stay on the Mac

IDEA, Maven, Gradle, ~/.m2 and your projects are mounted, so the image stays small and updates are a download.

safety

Authenticated X11

The XQuartz cookie is copied in on every start, so xhost + is not needed. See XQuartz.md.

git & ssh

Credentials carried over

Your ~/.gitconfig is included, and Docker Desktop forwards the macOS SSH agent into the container.

tests

Checked end to end

tests/sctp.sh builds the image and runs a loopback SCTP association in privileged and unprivileged containers.

Quick start

Three steps

You need curl, Docker and XQuartz.

01 Set up XQuartz

On the Security tab enable Authenticate connections and Allow connections from network clients, then restart XQuartz. The XQuartz guide has screenshots of every tab.

02 Start the IDE

Terminal
$ ./idea.sh --dry-run # what would be downloaded and which docker commands would run
$ ./idea.sh           # the newest local installation, or the latest release

03 Check SCTP

Terminal
$ docker exec idea-IU checksctp
$ docker exec idea-IU sysctl net.sctp.auth_enable net.sctp.udp_port net.sctp.encap_port
Settings

Environment variables with an IDEA_ prefix

Export them or put them in front of the command, for example IDEA_JDK_VERSION=21 ./idea.sh. The full list is in the README.

VariableDefaultMeaning
IDEA_PROJECTS_PATH./IdeaProjectsHost directory mounted as ~/IdeaProjects
IDEA_RELEASElatestPinned IDEA release, <version>@<build>
IDEA_JDK_VERSION25JDK in the image, 21 or 25 on CentOS Stream 10
IDEA_PORTSnonePublished ports, e.g. "8080:8080 5005:5005"
IDEA_PRIVILEGEDtrueRun with --privileged to change sysctl and create network namespaces
IDEA_SCTP_AUTH_ENABLE1net.sctp.auth_enable, SCTP authentication
IDEA_SCTP_UDP_PORTnonenet.sctp.udp_port, receive SCTP over UDP on this port
IDEA_SCTP_ENCAP_PORTnonenet.sctp.encap_port, send SCTP over UDP to this port
Good to know. The options are fixed when the container is created. idea.sh warns when an existing container differs from the settings; recreate it with docker rm idea-IU && ./idea.sh iu, the home volume is kept.
